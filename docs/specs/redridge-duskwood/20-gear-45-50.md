## The rules

`line` cell, then `build_gear.py`; a row copies its Line's icon from the Line's earlier rows, and
a Line's first row picks a free stock icon `icon_check.py` accepts; band levels, budgets, Flavours,
armour, Pickup, one Wardrobe set for the band's four green Chests, a name stem for the band.
